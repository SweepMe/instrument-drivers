# Switch (Simulation Driver)

**Module**: Switch

## Description

A simulated voltage source for developing and testing Switch sequences without hardware. The voltage that is set is
also returned. No instrument connection is required.

## Usage

1. Add the Switch module and select this *Simulation Driver*.
2. Pick the **SweepMode** `Voltage in V` and sweep the voltage, or `None` to return 0 V.

## Returns

- **Voltage** (V) — the applied voltage.
